# Sia private-alpha support

Use the private alpha support channel or contact the person who supplied your build.
There is no public support SLA during the alpha.

Include:

- the Sia version and macOS version;
- what you expected and what happened;
- the provider and feature involved;
- reproducible steps and a redacted screenshot when useful;
- whether the problem survives restarting Sia.

Do not send passwords, one-time codes, API keys, OAuth tokens, cookies, Keychain items, private
workspace contents, or an unredacted local database. For data deletion, use Settings → Apps rather
than sending account credentials to an operator.

The alpha is supported on macOS 14 or later. Updates are distributed manually through the same
private channel; install only signed and notarized artifacts supplied there.
