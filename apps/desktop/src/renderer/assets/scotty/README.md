# Scotty artwork

`scotty.png` is Sia's bundled, original Scottish-terrier sprite atlas. It is a transparent
1024 × 1536 RGBA PNG: four 256 × 256 frames per row, six rows (idle, trot, working/sniffing,
curious/waiting, happy, sleeping). The renderer displays this file locally and uses CSS steps;
there is no runtime image-generation service or Codex pet dependency.

Created using the built-in image-generation tool. Prompt:

> Create a production pixel-art animation sprite sheet for a desktop companion named Scotty,
> bundled inside the Sia app. One transparent PNG, exactly 1024 × 1536, in a uniform four-column,
> six-row grid of 256 × 256 cells. Every cell contains the same charming black Scottish terrier
> with pointed ears, a long boxy whiskered muzzle and beard, short legs, upright tail, dark
> charcoal fur with slate highlights, bright eyes, and a small red tartan neckerchief inspired
> by Carnegie Mellon's Scotty. Original artwork without official logos or lettering. Authentic
> pixel art with hard square pixels and a limited palette. Consistent scale and baseline,
> complete dog contained in each cell with generous transparent margins. Three-quarter side
> profile facing right. Four frames each: idle breathing/blink/wag; in-place trot; attentive
> working/sniffing; sitting and looking up with an inquisitive head tilt; happy hop and wag;
> curled-up sleeping and subtle breathing. No background, baked-in checkerboard, shadows,
> props, text, symbols, or watermark. Exact grid spacing and stable character scale matter.

The name and breed reference [CMU's Scotty mascot](https://brand.cmu.edu/messaging/heritage).
This is an original companion illustration, not a copied university mark.
