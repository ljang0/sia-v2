Help and recovery

Support

Start with the matching issue below. Never send a password, one-time code, OAuth secret, recovery key, or raw access token by email.

Sign-in code

You can create a Sia account with your email. Check spam and institutional quarantine, verify the displayed email, wait a minute, then request one new code. Only the newest code should be used.

Get sign-in help

Google connection

Start from Connected apps in Sia and press Connect Google. Choose the intended account, approve read access, and return to Sia. Enable editing later only if you need Sia to change files or send drafts. A 403 from an unverified release usually means the address is not yet an approved tester.

Get Google help

Slack connection

Connect through Sia, choose the workspace, and select Allow. The connection uses browser OAuth and does not depend on the desktop Slack app, a plugin, or a user-provided API key.

Get Slack help

Computer use

Allow the Accessibility and Screen Recording permissions Sia asks for. Sia works in the background, so you can keep using your Mac while it works. To watch it use your screen instead, choose On my screen in Settings → Computer. Sia keeps your display awake during a task and pauses if your Mac locks or goes to sleep. Unlock your Mac and press Continue task to pick up where it stopped. Some apps can't be controlled this way, so a connection built for that app works better when there is one.

Get computer-use help

Schedules

Open the original thread to view, pause, change, or remove its schedules. Alpha schedules run only while Sia is open and the Mac is awake.

Get schedule help

Export or delete data

Use the Research archive controls in Sia for export, research-only deletion, or account deletion. Contact us from the email associated with the account if the workflow fails.

Make a data request

What to include

Include the Sia version, your macOS version, the time and timezone of the issue, the feature involved, and the exact visible error text. You may attach a screenshot only after removing secrets and unrelated private content.

Security concerns

If you believe credentials, participant data, or connected-service access may have been exposed, stop the affected task, disconnect the relevant service if safe to do so, and contact security@superintelligentagents.ai.

Do not include an active credential or the private data of another person in the first message. We will coordinate a safer transfer method if evidence is needed.
