Download for Mac

Start in a few steps

  1. Open the disk image, drag Sia to Applications, then open Sia.
  2. Sign in with the code emailed to you. Use Set up Codex to download the supported version and sign in to your ChatGPT plan through your browser. No Terminal or model API key is needed.
  3. Use Set up permissions and approve the macOS prompts for the capabilities you want. Sia shows what is ready.

You need internet access and an eligible Codex plan. Separately connected Google Workspace and Slack accounts are still limited to designated testers; computer use can work through your existing Mac apps.

Choose how Sia works

Automatic action approval is selected during setup. You can choose confirmations instead. Mac permissions and sign-in screens still require you.

Background computer use is experimental. You can allow brief foreground control when an app cannot accept background input. Scheduled tasks require Sia to stay open and your Mac to stay awake.

Research sharing is off unless an eligible participant separately opts in. Read the privacy policy and terms before using Sia.

Keychain and updates

Sia uses macOS Keychain to protect saved settings and conversations. Normal launches and updates should retain access. A locked Keychain or a change from a development build can require authorization. Your Mac password is entered only in the macOS dialog.

Get help at support@superintelligentagents.ai. Never send your password, sign-in code, or API keys.
